# osysharp/memory

Osy# packages, one per folder. Each folder is a package of its own, with its own README, tests and releases (tagged `<folder>/v<version>`).

| Folder | Package | What it is |
|---|---|---|
| [`testing/`](testing/) | `Osysharp.Memory.Testing` | a deterministic, offline embedder for tests — a hashed bag of words — so a suite can assert what Memory.Search and [Searchable(Memory)] find without a model. |
